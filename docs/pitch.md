# ピッチ台本（下書き）: 言い間違い図書館

上位10チームに入ったときの、2〜3分の台本。持ち時間は当日に確認する。順番は、痛み → 解決 → デモ → 仕組み → 人が介在するところ。
目安: 日本語は1分で約300字。本文は約800字（2分40秒）。

## 台本（約2分30秒）

**① 痛み・出発点（35秒）** ← 一番、熱を込める
「子どもの言い間違いって、本当にとにかく可愛いんです。でも、あまりに日常に溶け込んでいるから、いつの間にか正しい言葉に"卒業"してしまって、あとから『あの時なんて言ってたっけ？』と思い出そうとしても、もう思い出せなくて、本当に悲しいんです。この『思い出せない悲しさ』をなくしたい！というのが、私たちの出発点です。（『てびり』『とうもころし』…）卒業の日は、誰にも記録されていません」

**② 解決（25秒）**
「そこで作ったのが『言い間違い図書館』です。子ども部屋に古いスマホを置いておくだけ。声を感じたときだけ録音して、言い間違いを自動で見つけ、**声のまま**図書館に並べます。手で書く面倒も、あとで探す面倒もありません。物差しの上に、日付つきで、成長の記録として並びます」

**③ デモ（50秒）**
（公開 URL か、GIF を映す）
「お母さんの画面です。ことばとりが、新しい言い間違いを『おてがみ』で運んできます。これは、実際に、うちの子どもが言った『てびり』。**再生ボタンを押すと、本当の声が聞けます**。何度も言うと、卵が孵って、ことばとりに育ち、卒業すると飛び立ちます」

**④ 仕組み（30秒）**
「音声は、AquaVoice の文字起こしで文字にして、AI で言い間違いを判定します。ここで、AquaVoice が効きました。普通の文字起こしだと、『さんとさん』は『ほんとさ』に、『てびり』は『テレビ』に、**正しい言葉に直されて、言い間違いが消えます**。でも、図書館に入った言葉をヒントとして渡すと、聞こえたまま書けました。使うほど、家族の言い間違いを覚えていきます」

**⑤ 人が介在するところ（20秒）**
「そして、最後に決めるのは、お父さん・お母さんです。誰が言ったか、正しい言葉、卒業した日。声を聞いて、確かめられます。それでも、『とうもころし』は、ヒントがあっても直されました。だから、**文字起こしが間違っても、声という一次情報は消えない**ように、音声クリップそのものを残しています」

**⑥ 締め（10秒）**
「卒業は、いつ来るか分かりません。だから、何もしなくても、残る。『言い間違い図書館』でした」

## 出発点（テーマの決まり方）
- 岩田さん: 「子どもの言い間違いは、言語学的にも価値があるのに、残されづらい」という視点（文学部時代に聞いた話）。
- 麻生さん: 「自分も思い出そうとしても思い出せなくて、悲しい」という実感。
- この2つが重なって、テーマが、単なる「家事の面倒を減らす」から、**「一生後悔する、"忘れちゃう悲しさ"をなくす」**に決まった。
- 質問で「テーマとどうつながるか」と聞かれたら、まずこの話をして、そのあとに、「書き留める面倒」「探す面倒」を減らす、と続ける。

## 話すときのコツ
- ①は、原稿を見ずに、自分の言葉で。ここで気持ちを掴む。
- 数字や固有名詞は、ゆっくり言う（「ほんとさ」「てびり」）。
- ③の「声を再生する」は、会場の音量が出るか、**直前に確認**する。出ない場合は、GIF と、言葉の説明で代用する。
- 「実際の子どもの声」は、4本だけ試した事実を、聞かれたら正直に言う。

## 想定質問と答え
| 質問 | 答え |
| --- | --- |
| プライバシーは？ | 声があるときだけ録音・送信する。保存は、音声も写真も、ブラウザの中だけ。ただし、文字起こしのために音声は AquaVoice に、判定のために文字は AI に送られる。「外部に出さない」とは言わない |
| なぜ音声である必然性は？ | 手が離せない場面で入力できない。そして、言い間違いは、文字にした瞬間に直されて消える。音声だから、言い間違いを声ごと残せる |
| AquaVoice のどこが良かった？ | ①素の文字起こしを選べる ②ヒントで文脈を渡せる ③話者分離が同じ API で使える ④ブラウザの録音をそのまま送れる ⑤日本語指定 ⑥料金が常時録音と相性が良い（他社と比べたわけではない） |
| 精度は？ | 本物の子どもの声は4本だけ。ヒントありで、3本は聞こえたまま書けた。「とうもころし」は直された。一般化はしない |
