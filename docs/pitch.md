# ピッチ台本（下書き v2）: いいまちがいとしょかん

上位10チームに入ったときの、2〜3分の台本。持ち時間は当日に確認する。
- **スピーカーは岩田さん（メイン）。** 子どもへの愛情の部分だけ、麻生さんに、**インタビュー形式**で語ってもらう。
- 名前は、話すときも書くときも、**「いいまちがいとしょかん」（ひらがな）**。
- 岩田さんには子どもがいない。「うちの子」とは言わない。子どもの話は、麻生さんに任せる。
- 目安: 日本語は1分で約300字。全体で約2分50秒。時間が足りないときの削り方は、末尾に。

## 台本

**⓪ 掴み（15秒）** 〔岩田〕 ← 会場に問いかける。少し間をとる
「みなさん、お子さんや、ご自身が小さい頃、**言い間違えていた言葉**、覚えてる人いますか〜？（間・手を挙げてもらう）
…ありがとうございます。じゃあ、**その言葉を、いつ言わなくなったか**、覚えてる人は？（間）
…ですよね。私も、覚えていません。（〔自分の小さい頃の言い間違いが1つあれば、ここで一言。なければ省略〕）」

**① 出発点：インタビュー（50秒）** 〔岩田 → 麻生〕 ← 一番、熱を込める。台本を見ずに
岩田「今日は、実際に、お子さんがいる、麻生さんに来てもらっています。麻生さん、お子さんの言い間違い、どうですか？」
麻生「（〔言い間違いが、どれだけかわいいか。実際の言葉を1つ〕）」
岩田「それを、覚えていますか？」
麻生「**子どもの言い間違いって、本当に、とにかく可愛いんです。でも、日常に溶け込みすぎていて、いつの間にか、正しい言葉に"卒業"してしまう。あとから『あの時、なんて言ってたっけ？』と思い出そうとしても、もう思い出せなくて、本当に悲しいんです。**」
岩田「それが、このアプリの、出発点なんですね」
麻生「はい。この**『思い出せない悲しさ』をなくしたい**。それだけです」
岩田（受けて）「私は、大学で言語学に触れたとき、**子どもの言い間違いは、言語学的にも価値があるのに、ほとんど残らない**、と聞きました。研究にも、思い出にも、なるのに、**卒業の日は、誰にも記録されていません**。忙しいお父さん・お母さんには、書き留める余裕も、ありません」

> インタビューの注意: 麻生さんの答えは、**短く、自分の言葉で**（各15秒以内）。①の太字は、麻生さんが、自分で言った言葉。そのまま、使ってよい。

**② 解決（20秒）** 〔岩田〕
「そこで作ったのが、『いいまちがいとしょかん』です。子ども部屋に、使わなくなったスマホを置いておくだけ。声を感じたときだけ録音して、言い間違いを自動で見つけて、**声のまま**、図書館に並べます。手で書く面倒も、あとで探す面倒もありません」

**③ デモ（40秒）** 〔岩田〕 ← 画面を映す（公開 URL か GIF）
「お父さん・お母さんの画面です。柱の背比べのような物差しに、日付つきで並びます。ことばとりが、新しい言い間違いを『おてがみ』で運んできます。これは、実際の子どもの声から登録した、『てびり』。**再生ボタンを押すと、本当の声が聞けます**。何度も言うと、卵が孵って、ことばとりに育ち、卒業すると、飛び立ちます」

**④ 仕組み（30秒）** 〔岩田〕
「音声は、AquaVoice で文字にして、AI で言い間違いを判定します。ここで、AquaVoice が効きました。普通の文字起こしだと、『さんとさん』は『ほんとさ』に、『てびり』は『テレビ』に、**正しい言葉に直されて、言い間違いが消えます**。でも、図書館に入った言葉をヒントとして渡すと、聞こえたまま書けました。使うほど、家族の言い間違いを、覚えていきます」

**⑤ 人が介在するところ（15秒）** 〔岩田〕
「最後に決めるのは、お父さん・お母さんです。誰が言ったか、正しい言葉、卒業した日。声を聞いて、確かめられます。それでも、『とうもころし』は、ヒントがあっても直されました。だから、**文字起こしが間違っても、声という一次情報は消えない**ように、音声そのものを残しています」

**⑥ 締め（10秒）** 〔岩田 → 麻生が一言〕
岩田「さっき、思い出せなかった言葉。これからは、残せます」
麻生（任意・一言）「卒業する前に、声で残したいです」
岩田「『いいまちがいとしょかん』でした。ありがとうございました」

## 話すときのコツ
- ⓪は、本当に、会場に聞く。手が挙がらなくても、「ですよね」で受ける。ここが、あとの「思い出せない悲しさ」への、伏線になる。
- ⑥で、⓪の問いに戻ると、きれいに終わる。
- 麻生さんは、①で出てきて、⑥で一言だけ。ほかは、岩田さんが話す。
- 数字や固有名詞（「さんとさん」「ほんとさ」「てびり」）は、ゆっくり言う。
- ③の「声を再生する」は、会場の音量が出るか、**直前に確認**する。出ない場合は、GIF と、言葉の説明で代用する。
- 「実際の子どもの声」は、4本だけ試した事実を、聞かれたら正直に言う。
- ロゴの「いいま**さ**がい としょかん」は、名前まで、ちょっと言い間違えている、遊びのデザイン。聞かれたら、そう答える。

## 時間が足りないときの削り方
1. ④の、「使うほど覚えていきます」を削る。
2. ③の、ことばとりの成長の説明を削る。
3. ⓪の、2つ目の問い（いつ言わなくなったか）を削る。
4. それでも足りなければ、⑤の「とうもころし」の部分を削る（聞かれたら答える）。
※ ①のインタビューと、⑥の締めは、削らない。

## 想定質問と答え
| 質問 | 答え |
| --- | --- |
| プライバシーは？ | 声があるときだけ録音・送信する。保存は、音声も写真も、ブラウザの中だけ。ただし、文字起こしのために音声は AquaVoice に、判定のために文字は AI に送られる。「外部に出さない」とは言わない |
| なぜ音声である必然性は？ | 手が離せない場面で入力できない。そして、言い間違いは、文字にした瞬間に直されて消える。音声だから、言い間違いを声ごと残せる |
| AquaVoice のどこが良かった？ | ①素の文字起こしを選べる ②ヒントで文脈を渡せる ③話者分離が同じ API で使える ④ブラウザの録音をそのまま送れる ⑤日本語指定 ⑥料金が常時録音と相性が良い（他社と比べたわけではない） |
| 精度は？ | 本物の子どもの声は4本だけ。ヒントありで、3本は聞こえたまま書けた。「とうもころし」は直された。一般化はしない |
| 複数の子どもは分かれる？ | 話者分離は使えるが、2人以上の子どもが同時に話す場面は、本物の声では未確認。誰が言ったかは、人が選べる |
| 「面倒を減らす」というテーマとの関係は？ | 記憶しておくには、毎回手で書かなければならず、それが面倒。思い出す・探すのも面倒。その2つの面倒を減らす。そして、「思い出せない悲しさ」をなくす |
| 子どもがいないのに、なぜ？ | 言語学の視点で、言い間違いは価値があるのに残らない、と知ったのが出発点。子どもへの愛情の部分は、親である麻生さんの実感が、核になっている |
| 今後は？ | 実機のスマホと、より多くの子どもの声での検証。ベビーモニターへの組み込み。「卒業」の自動判定。ケンカの仲裁（今日は捨てた機能） |
| 作った工夫は？ | 課題を言い間違い1本に絞った（自己審査で 150/300 点と出て、機能が多すぎると指摘された）。止まらない作り（AI が落ちても辞書ルールで動く） |
