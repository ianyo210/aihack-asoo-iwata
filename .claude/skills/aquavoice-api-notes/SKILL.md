# AquaVoice API の使い方（実測ベース）

## 選ぶべきエンドポイント
- **素の文字起こし `audio/transcriptions`** を使う。整形済みの `dictations`（単一話者・10分まで・整形あり）は、言い間違いを**直してしまう**ので避ける。
- 主なパラメータ: `model=avalon-2`、`language=ja`、`diarize=true`、`response_format=diarized_json`、`prompt`（ヒント）。
- 話者分離の応答は、話者ごとの「ターン」（話者ラベル・開始・終了・文）。ラベルは**録音ごと**の番号。別の録音の同じ人とは、限らない。

## ヒント（`prompt`）の効果
- **言い間違いを、聞こえたまま書かせたいときは、すでに知っている言葉の一覧を、ヒントに渡す。** 使うほど、覚えていく。
- 実測（本物の子どもの声、4本・1人だけ）: ヒントなしでは直される（さんとさん → ほんとさ、てびり → テレビ）。ヒントありで、3本は聞こえたまま。**限界**: 実在の言葉に寄る力が強いと、ヒントでも直る（とうもころし）。
- 対策: **音声クリップそのものを残す**。文字起こしが違っても、声という一次情報は消えない。

## 仕様・制限（公式サイトの調査）
- REST のみ（ストリーミングなし）。1ファイル最大4時間・256MiB。形式は `webm` ほか。
- 料金: 秒単位の課金。初回に無料枠あり（最新は、公式で確認）。
- MCP（OAuth・約27ツール）は、操作用で、**音声入力（ディクテーション）はできない**。
- ブラウザの録音（`webm`）は、そのまま送れる。

## 未確認（断定しない）
- 2人以上の本物の子どもでの、話者分離。機械音声の2人は、どちらも同じ話者と判定された。
- 「同期90分」などの、公式サイトの記載。他社との比較。

## 組み込みの注意
- キーは、**サーバー側**だけ。ブラウザに出さない。環境変数 `AQUA_API_KEY`（権限は、文字起こし）。
- 音声は、AquaVoice に送られる。プライバシーの説明は、正直に。
