# 議事録を、リポジトリに記録する

## 手順
1. 貼られた文字起こしを、最後まで読む。誤変換が多いので、**意味が取れる部分だけ**使う。
2. 記録先:
   - ミッション（クイズ）の発表・回答 → `MISSIONS.md` の表に1行（原文を短く・解禁時刻・制限時間・回答・送信時刻）。
   - 決定事項・方針転換 → `MISSIONS.md` の末尾に、見出し付きで追記。
   - 紆余曲折（記事のネタになる話） → `JOURNEY.md`。
3. 追記は、**日付・決まったこと・理由（Why）・捨てたこと**の順で書く。
4. 読み取れなかった数字・名前・点数は、**「不明」と書く**。推測で埋めない。
5. ユーザーが「pushして」と言ったら push する。言われていなければ、commit までにして、確認する。

## 注意
- 実在の個人名・子どもの本名・連絡先は書かない（仮名を使う）。鍵・パスワード・会場 Wi-Fi・プロモコードも書かない。
- Windows では、作業フォルダが CRLF になる。複数行の置換は、`split('\r\n').join('\n')` で正規化してから行う。
- 新しい議事録が、すでに記録した内容と**同じ**ことがある（貼り間違い）。まず、重複していないか確認し、新しい点だけ足す。
- 記録のあとに、「ピッチ・記事に使える視点」を、短く示す。
