# 言い間違い図書館

**AI HACK 2026 Special Oneday Hackathon** 提出作品（チーム：岩田 菜月 ＋ 麻生 大樹）。

> 「てビリ」と言っていたあの子の声を、卒業の日まで、声のまま残しておく。

子どもの言い間違いは、気づかないうちに「卒業」してしまいます。子ども部屋に置いたスマホが、声を感じたときだけ録音し、**Aqua Voice** の素の文字起こしと AI で言い間違いを見つけて、**音声クリップ付き**で「図書館」に自動で並べます。お父さん・お母さんは、あとで声を聞き返しながら、残す・直す・卒業日を決められます。

## 主な特徴

1. **押すだけ・自動で集まる**: 子ども側は「スタート」を押すだけ。声を感じたら録音し、無音で区切ります。見つけた言い間違いは、確認なしで図書館に入ります。
2. **声のまま残す**: 言い間違いは、文字にすると直されて消えます。そこで音声クリップそのものを保存し、「声」ボタンで本当の発音を聞き返せます。
3. **Aqua Voice の素の文字起こし ＋ 話者分離**: 整形済みでなく `audio/transcriptions`（`avalon-2`・日本語指定・`diarize=true`）を使い、言い間違いが直されにくくしています。
4. **AI（Gemini）で言い間違いを判定**: 辞書にない言い間違いも見つけます。AI が止まっても、辞書ルールで続けます。
5. **時系列の一覧・頻度・子どもごと**: 新しい順に並び、詳細で頻度（通算・直近7日・1週間あたり・日別）が分かります。子どもは最大6人まで登録できます。
6. **人があとで決める**: 誰が言ったか・正しい言葉・卒業した日・写真・図書館から外す、はお父さん・お母さんが決めます。

保存は、音声クリップも写真も、すべてブラウザの中です（`localStorage` と IndexedDB）。ただし、文字起こしのために音声は Aqua Voice に、判定のために文字は AI に送られます。

## 起動方法

マイクはブラウザの仕様で **HTTPS が必須**（`localhost` のみ例外）なので、スマホで使うときは **Vercel にデプロイ**します。

1. Vercel でこの GitHub リポジトリをインポート（ビルドコマンド不要・Output Directory はそのままルート `/`）。
2. Vercel の Environment Variables に次を設定します（**鍵はコードにもログにも書きません**）。

   | 変数 | 用途 |
   | --- | --- |
   | `AQUA_API_KEY` | Aqua Voice の文字起こし（scope は `transcription`） |
   | `GEMINI_API_KEY` | Gemini による言い間違いの判定（未設定でも、辞書ルールで動く） |
   | `OPENROUTER_API_KEY`・`OPENROUTER_MODEL` | （任意）判定を OpenRouter に切り替える場合 |

3. デプロイしたあと、トップ（`/`）を開くと図書館（`/museum.html`、お父さん・お母さん側）に移ります。子ども側は `/room.html` です。
   - 環境変数を足したり変えたりしたあとは、**Redeploy** しないと反映されません。
   - 動作確認: `/api/transcribe` と `/api/detect` を開くと、鍵が設定されているかが JSON で出ます（`aquaConfigured`、`llm`）。

**ローカル**（Node.js v20 以上、外部パッケージ不要）: 鍵を環境変数に入れて `node server.mjs` を起動し、`http://localhost:3000/` を開きます。Vercel と同じ `/api/transcribe` と `/api/detect` が動くので、「録音ファイルから入れる」で文字起こしから判定まで通して確かめられます。最初から、デモの記録（例の子）が入っています。

**テスト**: `node --test test/mistakes.test.js`（34件）

## ファイル構成

- `room.html` / `museum.html` / `ui.css` — 子ども側・お父さん・お母さん側の画面
- `api/transcribe.js` — Aqua Voice の素の文字起こし ＋ 話者分離（Vercel の関数）
- `api/detect.js` — 言い間違いの判定（Gemini、失敗時は辞書ルール）
- `lib/mistakes.js` — 判定・登録・頻度・卒業などのロジック（純粋な関数。`test/` でテスト）
- `lib/store.js` — ブラウザ内の保存（localStorage ＋ IndexedDB）
- `lib/gemini.js` / `lib/openrouter.js` / `lib/prompt.js` — AI の呼び出しとプロンプト
- `index.html` / `api/analyze.js` / `server.mjs` — 旧デモ（今日は使わない）と、ローカル確認用のサーバー
- `manifest.json` / `icon.svg` / `vercel.json` — PWA の設定・アイコン・ヘッダ設定
- `docs/` — 要件と設計、Qiita 記事の素材　／　`article.md` — Qiita 記事の下書き
- `HACKATHON.md` / `MISSIONS.md` / `JOURNEY.md` — 大会の情報、ミッションの記録、開発の紆余曲折
