# 言い間違い博物館 ＆ みまもりママコーチ

**AI HACK 2026 Special Oneday Hackathon** 提出作品（チーム：岩田 菜月 ＋ 麻生 大樹）。

親の目がない子ども部屋の会話を **Aqua Voice × 声感知オート録音** で見守り、ケンカが起きたら **「2分前の発端 ＋ 子どもへの伝え方アドバイス」** を別室のお母さんのスマホ（PWA）へ届け、日々の言い間違いや卒業日は **「言い間違い博物館（写真添付対応）」** に残すアプリです。

## 主な特徴

1. **🎙️ 常時みまもり録音（声感知 VAD）＆ Aqua Voice ノーボタン発火**
   - 設置時に1タップで待機。無音時は音声データを保存・送信せず、声を感知した瞬間だけ自動で聞き取り、話し終わりで自動解析します。
   - Aqua Voice で入力欄へ文字が入ると 1.5 秒後にボタン操作なしで自動送信。画面上の家庭内キーワードタグにより Aqua Voice のディープコンテキスト認識を補助します。
2. **💬 子どもへの伝え方アドバイス ＆ 発端巻き戻し**
   - 直近 3 分間のローリングバッファから発端を整理し、**年齢別（幼稚園児 / 小学生）** に合わせた声かけセリフ・心理的コツ・NG 声かけ・3 分交代タイマーを提案します。
3. **🏛️ 言い間違い博物館（写真添付・翻訳・卒業アルバム）**
   - 「とうもころし ➔ とうもろこし」「てビリ ➔ テレビ」などの言い間違いを標本カードとして保存（お母さんの確認ボタン付き）。
   - 正しく言えるようになった瞬間に「🎓 卒業」として殿堂入りし、当時の写真（ブラウザ内ローカル完結）と Aqua Voice 音声メモを飾れます。

## ローカル起動方法

Node.js v20 以上があれば外部パッケージのインストール不要で動きます。

```bash
node server.mjs
```

ブラウザで以下を開きます：
- デモ用 2 画面（子ども部屋 ⇔ ママスマホ）：`http://localhost:3000`
- 子ども部屋端末のみ：`http://localhost:3000/?view=room`
- お母さんスマホ PWA のみ：`http://localhost:3000/?view=mom`

## Vercel デプロイ手順

1. Vercel でこの GitHub リポジトリをインポート（ビルドコマンド不要・Output Directory はそのままルート `/`）。
2. （任意）Vercel の環境変数 `GEMINI_API_KEY` を設定すると、`/api/analyze`（Serverless Function）で Gemini 2.5 Flash による動的解析が有効になります。未設定時は内蔵の日本語解析エンジンでそのまま動作します。

## ファイル構成

- `index.html` — 可愛い絵本・博物館風 PWA（子ども部屋見守り UI ＋ お母さんスマホ UI）
- `manifest.json` / `icon.svg` — PWA マニフェスト・アイコン
- `api/analyze.js` — Vercel Serverless Function 兼 ローカル解析ロジック（Gemini API ＋ 自動フォールバック）
- `server.mjs` — ローカル実行・SSE リアルタイム同期用サーバー
- `vercel.json` — Vercel ルーティング・ヘッダ設定
